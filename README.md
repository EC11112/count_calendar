# 计数日历

一个本地运行的网页日历：每天按一下 = 半天，按两下 = 一天，再按清除。
颜色深浅区分强度，左侧选项目，右侧看累计。

## 怎么用

双击 `index.html` 用浏览器打开即可。无需安装、无需部署。

> 提示：用 Chrome / Edge 打开效果最好。Firefox 也行。
> 用了 `localStorage` 存数据，**每个浏览器独立**——换浏览器或清浏览器数据会丢记录。

## 功能

- **点击计数**：日期格子点一下变浅色（半天），再点一下变深色（一天），第三次清除。循环 0 → 半 → 整 → 空。
- **三种视图**：
  - **月视图**（默认）：单月，prev/next 步进 ±1 月
  - **季视图**：3 个月作为 1 块横向流式展开。**列数随视口自适应**：手机竖屏 → 7 列（1 周/行），平板横屏 → 14 列（2 周/行），1080p → 21 列（3 周/行），2k+ → 28-35 列（4-5 周/行），4k → 35 列（5 周/行）。格子强制正方形，**统一字体**：weekday 标签和 date 数字都按 `cellSize * 0.7` 缩放（夹 20-40px），"半/整"徽章按 `cellSize * 0.5`（夹 9-24px）。格子 ≥ 35px 时切月视图样式：日期右上角、徽章左下角。点击「季」会锚定到当前所在季度。prev/next 步进 ±3 月
  - **年视图**：独立的年组件，1 块，12 个月连续流。**同样自适应**：极窄屏 → 7 列 53 行，1080p → 14-21 列 18-27 行，2k+ → 28-35 列 11-14 行，4k → 35 列 8 行。点击「年」会锚定到当前自然年（1–12 月）。prev/next 步进 ±12 月
  - **resize 监听**：窗口缩放时 debounce 100ms 重算布局，季/年/月视图全部自动重排
  - **视觉提示**：周末（`日` / `六`）对应的列标签和未填写的日期数字都显示为红色，已填写的格子仍按项目色显示
- **设置按钮（右上角 ⚙）**：调最大列数（7 的倍数，范围 7-49，默认 35）。存在 localStorage，刷新保留
- **今天按钮**：一键回当前时间。月份锚定：月视图 → 今天；季视图 → 当前季度首月；年视图 → 年初（`viewMonth = 0`）。如果 viewYear 不对（比如从下一年切回来），也会回到今年。
- **多项目**：左侧可以新建项目，每个项目配 8 种主题色，所有数据按项目分开。
- **跨月跨年**：顶部 ‹ › 翻页，"今天" 按钮一键回当前月。
- **统计**：右侧实时显示当前项目本月 / 本季度 / 本年 / 总计 / 折合小时（按 1 天 = 8h 估算）。
- **响应式**：窄屏（< 900px）自动单列布局，季/年视图 < 700px 改 2 列、< 480px 改 1 列。

## 快捷键

- 鼠标 hover 浮在日期上 → 出现 tooltip 式说明
- 项目名输入框支持回车提交、Esc 取消

## 数据说明

- 全部存在浏览器 `localStorage`，key = `count_calendar_v2`
- 想清空：在浏览器 DevTools Console 跑 `localStorage.clear()` 然后刷新
- 想换浏览器：暂不支持跨浏览器同步（本地工具，没做云端）

## 想改？

直接编辑 `index.html`：
- 改主题色：CSS 顶部的 `--bg` `--accent` 等变量
- 改色板：JS 里 `COLORS` 数组
- 改小时换算：JS 里 `HOURS_PER_DAY` 常量
- 改默认项目：JS 里 `DEFAULT_PROJECTS` 数组

## 已知限制

- file:// 协议下，Chrome 对 `localStorage` 行为有差异；如果你看到数据没保存，请确认用的是 https:// 或 http:// 服务。
- 暂不支持导入/导出。
- 没有暗色模式（虽然配色很好改）。
