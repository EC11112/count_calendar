# 计数日历

一个本地运行的网页日历：每天按一下 = 半天，按两下 = 一天，再按清除。
颜色深浅区分强度，左侧选项目，右侧看累计。

## 怎么用

双击 `index.html` 用浏览器打开即可。无需安装、无需部署。

> 提示：用 Chrome / Edge 打开效果最好。Firefox 也行。
> 用了 `localStorage` 存数据，**每个浏览器独立**——换浏览器或清浏览器数据会丢记录。

## 功能

- **点击计数**：日期格子点一下变浅色（半天），再点一下变深色（一天），第三次清除。循环 0 → 半 → 整 → 空。
- **三种视图**：
  - **月视图**（默认）：单月，prev/next 步进 ±1 月
  - **季视图**：3 个月并排（一行 3 列），prev/next 步进 ±3 月
  - **年视图**：12 个月 4 行 × 3 列（每行一个季度），prev/next 步进 ±12 月
  - 季/年视图每月顶部带 `日 一 二 三 四 五 六` 七列小标签，跨年月份自动带年份
- **多项目**：左侧可以新建项目，每个项目配 8 种主题色，所有数据按项目分开。
- **跨月跨年**：顶部 ‹ › 翻页，"今天" 按钮一键回当前月。
- **统计**：右侧实时显示当前项目本月 / 本季度 / 本年 / 总计 / 折合小时（按 1 天 = 8h 估算）。
- **响应式**：窄屏（< 900px）自动单列布局，季/年视图 < 700px 改 2 列、< 480px 改 1 列。

## 快捷键

- 鼠标 hover 浮在日期上 → 出现 tooltip 式说明
- 项目名输入框支持回车提交、Esc 取消

## 数据说明

- 全部存在浏览器 `localStorage`，key = `count_calendar_v2`
- 想清空：在浏览器 DevTools Console 跑 `localStorage.clear()` 然后刷新
- 想换浏览器：暂不支持跨浏览器同步（本地工具，没做云端）

## 想改？

直接编辑 `index.html`：
- 改主题色：CSS 顶部的 `--bg` `--accent` 等变量
- 改色板：JS 里 `COLORS` 数组
- 改小时换算：JS 里 `HOURS_PER_DAY` 常量
- 改默认项目：JS 里 `DEFAULT_PROJECTS` 数组

## 已知限制

- file:// 协议下，Chrome 对 `localStorage` 行为有差异；如果你看到数据没保存，请确认用的是 https:// 或 http:// 服务。
- 暂不支持导入/导出。
- 没有暗色模式（虽然配色很好改）。
